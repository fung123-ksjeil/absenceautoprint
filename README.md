# 결석계 자동 출력

## 개발

```sh
npm ci
npm run dev
```

검증: `npm run check`, `npm test`, `npm run build`.
프로덕션 실행: 빌드 후 `npm start` (기본 포트 5000).

## 학교 원본 HWPX로 저장·인쇄

1. 학번, 성명, 사유코드·내용, 시작일·종료일, 결석 일수, 제출일, 담임을 입력합니다.
2. 개별 학생은 미리보기에서 **원본 HWPX 저장**, 전체 학생은 **전체 결석신고서 다운로드**을 누릅니다.
3. 한 건은 HWPX, 여러 건은 학생별 HWPX가 들어 있는 ZIP으로 저장됩니다. ZIP은 먼저 압축을 풉니다.
4. 생성한 HWPX를 **한글에서 열어 입력 내용과 페이지 배치를 확인한 뒤 인쇄**합니다.

사유코드 0은 질병결석 양식, 1~13은 특별결석 양식을 사용합니다.
학교에서 제공한 `결석신고서(2026).hwpx`, `특별결석신고서(2026).hwpx`를 각각
`client/public/templates/sick.hwpx`, `special.hwpx`의 기본 양식으로 사용합니다.
원본에 채워진 예시 개인정보와 날짜·사유는 입력용 자리표시자로 바꾸고,
개인정보가 담긴 미리보기 이미지는 비워 공용 양식에 예시 개인정보가 남지 않도록 했습니다.
글꼴, 여백, 표, 결재란, 규정 문구는 이 파일에서 가져오며 빈칸에 해당하는 텍스트만 채웁니다.
수정한 문단의 기존 줄 배치 캐시는 제거하여 한글에서 다시 배치하도록 합니다.
썸네일 이미지는 비어 있으므로 파일 탐색기의 썸네일에는 입력 내용이 표시되지 않습니다.

파일 생성은 브라우저 안에서 처리하며 학생 정보를 별도 서버로 전송하지 않습니다.
화면 입력 내용은 새로고침하면 초기화됩니다. 필요한 파일을 먼저 저장해주세요.
GitHub Pages 배포에서도 같은 기능을 사용할 수 있도록 배포 기본 경로를 따릅니다.

웹 미리보기와 **웹 인쇄**는 기존 웹 양식입니다. 학교 원본 양식으로 제출할 때는 HWPX를 사용합니다.
한글에서의 최종 인쇄 결과는 이 Linux 개발 환경에서 검증하지 못했습니다.
원본 글꼴 설치 여부와 긴 사유 내용에 따라 줄바꿈·페이지 수가 달라질 수 있으므로 한글에서 확인해야 합니다.

## 양식 변경 시

`client/src/lib/hwpx.ts`는 업로드된 원본의 특정 텍스트 노드에 대응합니다.
템플릿을 바꾸면 입력 위치를 `{{studentName}}` 같은 자리표시자로 지정하고 `npm test`를 실행해야 합니다.
위치가 맞지 않으면 빈 문서를 잘못 저장하지 않도록 오류를 표시합니다.
